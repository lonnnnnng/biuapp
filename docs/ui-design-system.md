# Biu Android UI 设计规范

- 作者：long
- 更新日期：2026-08-01
- 适用范围：推荐与搜索、视频动态、UP 主中心、账号音乐库、分 P 选择、迷你播放器、全屏播放页

## 设计目标

Biu 是高频使用的音乐播放工具，界面以“快速扫描内容、立即播放、随时控制进度”为核心。新版采用近黑背景、深灰表面和绿色播放态，减少大面积留白和重复容器，让封面、标题、分 P 名称与播放控制成为首要视觉信息。

## 视觉语言

- 应用默认使用深色方案，同时支持亮色与跟随系统；常规页面颜色从 Material 语义色读取，视频画面使用纯黑底保证画幅外区域稳定。
- 绿色 `#3DDC84` 统一用于播放、缓冲/进度、当前分 P、导航选中和模式切换；非关键控件使用灰绿中性色。
- 卡片和图片圆角不超过 `8dp`，不使用嵌套卡片或装饰性渐变。
- 页面间距遵循 `4dp / 8dp` 节奏：页面边距 `16dp`，组件间距 `8dp`，区块间距 `16dp`。
- 推荐列表固定为“标题 / 发布时间 / 作者”三行小字；账号音乐库固定为“标题 / 已播放时长与总时长 / 作者”三行小字，两类标题都单行省略。用户可在“界面显示”选择小号、标准或大号字号，以及标准或紧凑列表密度。

## 组件规则

### 顶部栏

- 只展示当前页面标题，不重复展示 `BIU` 品牌字样，也不在标题下增加副标题。
- 推荐页只展示首页内容范围和 UP 主搜索；动态页只展示刷新；主题、音质和账号菜单集中在账号页。账号菜单提供“界面显示”，不额外挤占标题栏图标位。
- 所有标题栏图标入口保持 `48dp` 点击区域，并提供无障碍说明。

### 媒体列表

- 标准密度下推荐和账号音乐库的视频封面统一为 `88dp x 52dp`，本地音乐封面为 `48dp`；紧凑密度分别收缩为 `76dp x 45dp` 与 `44dp`，右下角按需展示时长。
- 推荐标题、发布时间和作者统一使用 `bodySmall`，各占一行；不在作者行混入播放量。
- 正在解析时禁用整行重复点击，并用进度指示替换播放图标。
- 分割线从文字区域开始，不穿过封面。

### 推荐与搜索

- 搜索框固定放在推荐页顶部，不再占用独立底部导航项。
- 推荐与在线历史搜索统一使用 `44dp` 紧凑搜索栏，搜索动作和清空动作放在输入框内部，不再使用外置大按钮或浮动标签。
- 未提交搜索时展示推荐源切换与推荐内容；提交后在同一位置展示搜索结果。
- 清空搜索词或点击“返回推荐”后恢复推荐内容，保留明确的加载与空结果状态。
- 首页范围没有配置时展示“综合热门 / 每周必看 / 全站排行 / 入站必刷”四个 Tab；选中关注 UP 后，每位 UP 独立成为一个 Tab。
- 推荐分类复用账号页 `48dp` Tab 和底部 `2dp` 选中指示线；UP 数量不固定时横向滚动，名称保持单行省略。
- 内容范围入口读取登录账号关注列表，支持按名称本地模糊搜索；保存 UID、名称、头像和选择顺序。
- 首页内容范围与 UP 主中心统一使用无拖拽把手的全高底部弹层、`56dp` 紧凑标题栏和显式关闭按钮；搜索框、列表分隔线及明暗主题均复用页面语义色。
- 首页内容范围的保存区固定在弹层底部，列表独立滚动；UP 主中心在列表与空间详情间切换时只改变弹层标题和返回动作，不重置首页浏览位置。
- 每位 UP 独立维护投稿缓存、下一页和首屏/续页加载状态；切换 Tab 不混合其他 UP 内容，配置增删保留未变化 UP 的缓存。
- 综合热门按服务端 `pn/ps/no_more` 翻页；每周必看按更早期数续载；全站排行和入站必刷固定列表只在客户端按 20 条分批展示，不发送伪分页参数。
- 推荐列表接近末尾时自动加载下一批，并在列表末尾显示紧凑进度状态；搜索结果不触发推荐分页。
- 推荐内容和搜索结果支持下拉刷新；刷新默认来源或当前 UP Tab 时不清空其他 UP 已加载内容。

### 页面状态

- 推荐和动态列表使用下拉刷新指示；动态标题栏同时提供刷新按钮并在请求期间显示进度，其他页面初始加载继续使用线性进度条。
- 空状态包含图标、标题和解释；需要登录时必须提供明确登录动作。
- 错误继续使用全局 Snackbar，保留原有恢复路径。

### 视频动态

- “动态”作为独立底部主导航，标题栏刷新按钮与列表下拉手势共用同一条刷新链路。
- 动态单项封面宽度为 `112dp`，高度按右侧四行文字的实际行高计算并保持等高；右侧固定为作者与纯日期时间一行、资源标题最多两行、点赞与三连一行。
- 动态单项使用 `16dp` 横向边距和 `4dp` 垂直边距；不再展示动态说明和独立播放图标，给 UP 名称与两行资源标题留出完整宽度。
- 点击媒体区域进入现有单 P/多 P 播放链路；点赞和三连使用 `24dp` 视觉高度的紧凑操作行，写操作期间以进度指示替换点赞图标并禁用重复点击。
- 点赞使用乐观反馈，失败后恢复原状态；三连必须先弹出确认框，明确展示视频名称以及点赞、投币、默认收藏夹三项影响。
- 列表接近末尾时使用服务端游标自动加载下一页；初始加载、续页加载、空内容、未登录和失败状态均保留独立反馈。

### UP 主中心

- 推荐源操作区提供独立 UP 主入口，不增加第三个底部主导航项。
- 搜索栏置于弹层内容顶部，其下使用与推荐、账号页一致的“用户搜索 / 我的关注”两个 `48dp` 下划线 Tab；用户搜索调用远端分页，关注列表分页读取并支持对已加载内容做本地名称筛选。
- UP 主列表使用 `44dp` 圆形头像、单行名称、UID/粉丝/投稿摘要和可选单行签名，单项不使用卡片容器。
- 点击 UP 主后在同一全高弹层内进入空间详情；资料头展示头像、名称、UID、认证、签名和关注状态，下方投稿复用推荐列表的 `88dp x 52dp` 紧凑行。
- 投稿按发布时间倒排并支持分页；播放和收藏操作沿用推荐列表行为。
- 关注写操作期间禁用重复点击；取关成功后同步从首页内容范围移除对应 UID，防止首页保留失效配置。
- 未登录仍可搜索和浏览空间；“我的关注”与关注按钮提供明确登录入口。

### 底部播放区

- 无播放内容时隐藏播放器，只保留主导航。
- 播放器分为媒体信息/控制行与进度行，标题使用普通字重的小字号，始终显示当前时间和总时长。
- 多 P 内容在进度条上方优先展示当前 P 名称，并使用绿色强调。
- 上一首与下一首图标视觉尺寸大于播放按钮图标；视觉尺寸变化不压缩 `48dp` 控制触区。
- 自定义进度条轨道为 `2dp`、播放点直径为 `8dp`，缓冲使用低透明绿色，触控高度保持 `48dp`。
- 拖动、上一首、播放暂停、下一首必须维持至少 `48dp` 点击区域。
- 点击媒体信息区域进入全屏播放页，避免进度拖动与页面跳转手势冲突。

### 全屏播放页

- 全屏默认只展示大封面、资源名称、当前 P 名称、作者、当前时间、总时长和播放控制，不固定占用下半屏展示列表。
- 播放列表入口位于进度条右上方，点击后从底部弹出可滚动列表。
- 弹层中的当前队列项使用绿色容器和播放图标双重标记；点击任意队列项立即切换并继续播放。
- Android 返回手势与顶部返回按钮均回到原页面，保留播放状态和主页面状态。
- 竖屏使用大封面上下结构，横屏使用封面与播放信息左右分栏；播放列表在两种方向下都保持底部弹层。
- 在线内容默认继续播放音频；竖屏切换到视频后，以 `16:9` 小窗替换原封面区域并保留页面顶部栏，不立即进入全屏。
- 竖屏视频小窗必须贴齐屏幕左右边缘，不留页面白边且不使用圆角；底部工具栏保持单行，实际高度约为播放器高度四分之一。
- 手机随系统自动旋转到横屏后，视频切换为可通过边缘滑动临时唤出系统栏的沉浸全屏；小窗全屏按钮和全屏退出按钮也可主动切换方向。
- 小窗和全屏共用覆盖式控制层，包含播放/暂停、上一 P/下一 P、进度拖动、倍速、实际可用画质、播放列表、方向切换和切回音频；点击画面收起或唤出，播放时自动隐藏。
- 视频模式不复用音频模式下方的资源信息、下载、进度和控制布局，避免画面被固定内容压缩。
- 顶部音视频模式切换使用播放视频图标，下方视频下载保留胶片图标，两种动作不能使用同一图形。
- 播放页只保留下载当前音频、下载当前视频和播放列表动作；下载任务列表统一从账号页下载 Tab 进入。

### 账号音乐库

- 收藏夹、在线历史、本地历史、本地音乐和下载使用单行五等分 Tab，删除稍后再看和两行入口卡片。
- 账号头部使用 `44dp` 头像并删除连接状态副标题，刷新、登录、更新或退出操作保持可达；下载列表不再放在账号头像菜单中。
- “我创建的”和“我收藏的”默认收起，分组标题保持 `48dp` 触控高度；收藏夹封面为 `40dp`，明细行不再额外增加上下留白。
- 在线内容与本地历史封面为 `88dp x 52dp`，右侧固定三行 `bodySmall`，第二行统一显示“已播放时长 / 总时长”，不显示收藏时间或播放量；本地音乐列表使用同一紧凑节奏。
- 下载 Tab 复用音频/视频任务控制、失败重试和仅非计费网络开关，不再弹出独立下载任务底部面板。

### 全高弹层

- 首页内容范围、UP 主中心与分 P 列表打开时跳过半展开状态，直接使用屏幕可用最大高度，关键操作不依赖再次上滑弹层。
- 首页内容范围的关注列表独立滚动，保存按钮固定在弹层底部并始终可见；未登录时按钮保留但不可用。
- 弹层提供显式关闭按钮、分 P 总数和“全部播放”主动作。
- 分 P 列表占满标题和主动作之外的剩余空间；每一 P 显示序号、名称和时长，名称与时长统一使用 `bodySmall`；队列加载期间禁止关闭和重复点击。

## 响应式与无障碍

- 主内容最大宽度 `840dp`，横屏时居中；全屏播放页横屏使用左右分栏。
- 所有图标按钮提供 `contentDescription`，导航同时使用图标与文字。
- 正文、次级文字和背景保持可读对比度；所有颜色从 Material 语义色读取，不在页面组件中散落品牌色常量。
- 系统字体放大时优先换行或省略，不让按钮文字与相邻控件重叠。
- 应用字号只派生 Compose 基准排版，不覆盖系统无障碍字号；紧凑密度只缩小封面和间距，不隐藏标题、时间/进度或作者。
