# Biu Android UI 设计规范

- 作者：long
- 更新日期：2026-07-29
- 适用范围：推荐、搜索、账号音乐库、分 P 选择、底部播放控制

## 设计目标

Biu 是高频使用的音乐播放工具，界面以“快速扫描内容、立即播放、随时控制进度”为核心。新版采用紧凑、安静的内容优先布局，减少大面积留白和重复容器，让封面、标题、分 P 名称与播放控制成为首要视觉信息。

## 视觉语言

- 主内容使用暖白背景与纯白表面，深色模式使用接近黑色的中性背景。
- Bilibili 粉统一用于播放、当前分 P、导航选中和模式切换；非关键控件使用中性炭灰，避免多种强调色互相竞争。
- 卡片和图片圆角不超过 `8dp`，不使用嵌套卡片或装饰性渐变。
- 页面间距遵循 `4dp / 8dp` 节奏：页面边距 `16dp`，组件间距 `8dp`，区块间距 `16dp`。
- 列表保持紧凑：封面固定比例，标题最多两行，作者、播放量和时长作为次级信息。

## 组件规则

### 顶部栏

- 左侧同时展示 Biu 品牌与当前页面标题，减少居中大标题带来的空白。
- 音质和账号入口保持 `48dp` 点击区域，并提供无障碍说明。

### 媒体列表

- 封面采用 `112dp x 72dp`，右下角展示时长。
- 标题最多两行；作者、播放量在下一行显示。
- 正在解析时禁用整行重复点击，并用进度指示替换播放图标。
- 分割线从文字区域开始，不穿过封面。

### 页面状态

- 加载状态显示线性进度条。
- 空状态包含图标、标题和解释；需要登录时必须提供明确登录动作。
- 错误继续使用全局 Snackbar，保留原有恢复路径。

### 底部播放区

- 无播放内容时隐藏播放器，只保留主导航。
- 播放器分为媒体信息/控制行与进度行，始终显示当前时间和总时长。
- 多 P 内容在标题下优先展示当前 P 名称，并使用品牌粉强调。
- 拖动、上一首、播放暂停、下一首必须维持至少 `48dp` 点击区域。

### 分 P 选择

- 弹层提供显式关闭按钮、分 P 总数和“全部播放”主动作。
- 每一 P 显示序号、名称和时长；队列加载期间禁止关闭和重复点击。

## 响应式与无障碍

- 主内容最大宽度 `840dp`，横屏时居中，避免长行跨越整个屏幕。
- 所有图标按钮提供 `contentDescription`，导航同时使用图标与文字。
- 正文、次级文字和背景保持可读对比度；浅色和深色使用独立语义色。
- 系统字体放大时优先换行或省略，不让按钮文字与相邻控件重叠。
